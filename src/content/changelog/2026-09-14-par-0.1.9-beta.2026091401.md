# Pär v0.1.9-beta.2026091401

## What’s new in Pär v0.1.9-beta.2026091401

### Added

- **Pär Home Hub**: Turn your Mac into a private home hub over local Wi-Fi. Companion devices (phones, tablets, secondary laptops) can connect and pair via a secure 6-digit PIN with zero external cloud dependencies.
- **Progressive Web App (PWA)**: Companion devices can now open Pär in Safari or Chrome and install it directly to their home screen as a standalone full-screen app.
- **Household Member Profiles**: Multi-member household isolation allows family members to share a single Home Hub while keeping their conversations, personal tasks, and memories completely private and isolated.
- **Encrypted Vector Store**: Vector search embeddings and semantic cache entries now persist directly inside the SQLCipher-encrypted vault (`peer.db`), with two-stage candidate retrieval and member partitioning.

### Security

- Added default-deny authentication middleware for all incoming local network requests, ensuring only paired devices with cryptographically signed tokens can access Home Hub endpoints.
- Eliminated plaintext vector and document chunk storage on disk by migrating vector persistence into the encrypted database.
