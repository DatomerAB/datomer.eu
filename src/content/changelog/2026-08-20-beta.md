# Beta release

We opened the private beta to a small group of macOS users.

## Highlights

- First end-to-end encrypted memory graph.
- Background sync for Google Calendar and Gmail.
- Initial routine templates: Morning Briefing, Weekly Review, Inbox Zero.

## Learnings

Beta testers told us the biggest pain point with existing assistants is repetition — having to re-explain context every session. That insight became the core design principle for Pär.
