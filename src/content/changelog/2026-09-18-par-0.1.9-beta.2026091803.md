# Pär v0.1.9-beta.2026091803

## What’s new in Pär v0.1.9-beta.2026091803

### Added

- **Dual-Port Home Hub (HTTP & HTTPS)**: Home Hub now runs simultaneous listeners
  for plain HTTP on port 7433 and secure HTTPS on port 7434. Companion devices can
  connect instantly via HTTP without browser certificate warnings, or connect via
  HTTPS for in-browser speech recognition and standalone PWA installation.
- **Automated TLS & Network Adaptation**: Certificates are generated and refreshed
  automatically with SANs tracking local IP changes and mDNS/Bonjour hostnames.
  Root CA certificates can be downloaded directly from `/api/hub/ca.crt`.
- **Adaptive Mobile Dictation**: Companion web UI provides tailored guidance for
  phone keyboards to dictate directly in HTTP mode without browser permission blockers.

### Fixed

- **Companion Asset Loading**: Resolved symlink path normalization under macOS
  PyInstaller environments so frontend JavaScript, CSS, and font bundles load
  reliably without 404 errors.
- **Bonjour Hostname Protocol Alignment**: Aligned protocol schemes and port numbers
  for Bonjour/mDNS addresses between HTTP and HTTPS modes.
