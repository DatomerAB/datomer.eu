# Pär v0.1.9-beta.2026091802

## What’s new in Pär v0.1.9-beta.2026091802

### Fixed

- **Release Notes Timing**: The automated release now writes the customer-facing
  release notes to the draft release immediately after the DMG is uploaded,
  instead of waiting until after Apple notarization completes (which can take
  1-4 hours). Publishing a draft for early testing no longer produces an empty
  public release body that fails the downstream par-releases publish check.
- **Model Download Progress**: GGUF model downloads now stream directly and
  report live progress on the Models page instead of showing a stuck 0% until
  completion.
- **Model Delete Button**: Fixed the desktop app's delete button sending the
  wrong HTTP method, which caused every delete attempt to fail with a
  "Method Not Allowed" error.
- **EU AI Act Catalog Compliance**: Removed a therapy-tagged model that had
  leaked into the local model catalog from an older catalog bundle predating
  the compliance exclusion list.
