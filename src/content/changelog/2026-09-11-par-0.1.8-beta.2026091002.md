# Pär v0.1.8-beta.2026091002

## What’s new in Pär v0.1.8-beta.2026091002

### Fixed

- The bundled Python sidecar now starts reliably instead of leaving the app on
  a blank window, and reports clean diagnostics when it cannot start.
- "Could not save model preference" no longer appears when switching models
  quickly. Rapid clicks are debounced so the selection is saved once.
- Models whose catalog entries omit `model_uid` now get a stable identifier, so
  preferences and routing stay attached to the right model between launches.

### Security

- Rotated the updater signing key and resolved npm audit findings in the
  desktop dependency tree.

### Changed

- **This build must be installed manually from the DMG.** The updater signing
  key changed, so existing installs cannot verify this update. Conversations,
  models, license, and settings are preserved: they live in `~/.peer/`, outside
  the app bundle.
