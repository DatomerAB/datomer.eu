# Pär v0.1.9-beta.2026091502

## What’s new in Pär v0.1.9-beta.2026091502

### Fixed

- **Home Hub LAN Connectivity**: Configured desktop sidecar to bind `0.0.0.0:7433` so mobile devices on the local Wi-Fi network can reach the Home Hub. Non-loopback requests remain strictly guarded by `HomeHubAuthMiddleware`.
- **Dynamic Bonjour Discovery**: Resolved `DNS_PROBE_FINISHED_NXDOMAIN` errors by automatically resolving the machine's actual system Bonjour hostname (`<LocalHostName>.local` on macOS) instead of a hardcoded static hostname.
- **Direct IP & QR Code Prioritization**: Prominently displays the Direct IP address and on-screen pairing QR code as the primary pairing method for all companion devices, with an explicit advisory for Android/Chrome regarding `.local` mDNS limitations.
