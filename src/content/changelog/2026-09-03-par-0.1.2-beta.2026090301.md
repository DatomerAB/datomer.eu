# Pär v0.1.2-beta.2026090301

We're excited to share Pär v0.1.2-beta.2026090301, a release focused on making the app start faster, stay reliable, and give you more control over your models and integrations.

## What's new

### Faster startup
- Pär now starts in the background while license checks and model attribution run asynchronously.
- Ollama and other local model probes no longer block the main loading path.
- Routing configuration is loaded once and reused, cutting redundant work on every launch.

### Smarter context handling
- The Personal Context Graph is now more resilient: transient provider errors are retried with backoff, and repeated failures are surfaced through a clear health endpoint.
- Context items now carry freshness and TTL controls so Pär can keep relevant context fresh without accumulating stale data.
- Integration refresh can be forced from the UI or API when you need an immediate update.

### More control over models and licensing
- Reload the model catalog at runtime without restarting the app.
- Reload a license key on demand from the UI or API.
- License validation runs in the background and reports status through the existing health checks.

### Workflow and release improvements
- Daily model-catalog discovery now has the right permissions and labels to open its automated draft PR.
- Cross-repo notifications use a shared composite action so Slack alerts always have proper checkout context.
- Release notes are now generated from a shared template, and future releases will be blocked if business-readable notes are missing.
- The datomer.eu changelog now links to the website download form instead of raw GitHub asset URLs.
