# Pär v0.1.5-beta.2026090807

This beta release improves the chat experience and hardens the release pipeline.

## What's new

- **Inline chat-history suggestions:** start typing in the chat input and Pär surfaces matching previous conversations by title. Paid tiers also see semantic matches. Navigate with arrow keys and press Enter to reopen a chat.
- **Favourite chat backgrounds:** paid-tier users can choose from gradient presets or upload a custom background image. Selections are persisted locally and loaded through Tauri's scoped asset protocol.
- **Version sync from git tag:** release builds now automatically align `package.json`, `package-lock.json`, `tauri.conf.json`, and `Cargo.toml` with the git tag, so the shipped app always reports the correct version.
- **Pre-release readiness checks:** a new local checklist (`scripts/check_release_ready.sh`) verifies tooling, version sync, attribution, lint, tests, and desktop build health before a tag is pushed.
