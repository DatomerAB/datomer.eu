# Pär v0.1.9-beta.2026091603

## What’s new in Pär v0.1.9-beta.2026091603

### Added

- **Self-Contained Receipt & Scanned PDF Extraction**: Integrated `pypdfium2` (bundling Google PDFium C library) and `rapidocr-onnxruntime` in `core/document_extract.py` and `api/routes/chat.py` to extract text from scanned receipts and image PDFs completely offline with zero host system dependencies (no external `poppler` or `tesseract` binaries required).
- **Sticky Auto-Scroll & Frontier Cursor**: Added threshold-aware scroll tracking (`isAtBottom <= 80px`) with a floating "↓ Jump to latest" button when the user scrolls up, and replaced bulky thinking cards with an inline pulsing cursor (`▍`) on the active assistant response.
- **Regenerate & Clipboard Paste**: Added a one-click "↺ Regenerate" button on assistant messages and direct `onPaste` file attachment handling for clipboard images, receipts, and documents.

### Fixed

- **Eliminated Meta-Reasoning Output Leaks**: Added prompt-leak trimming (`_trim_meta_reasoning`) in `agent/peer_agent.py` to intercept and strip internal model deliberation ("We are given a user query...", "However, in the context provided...") and `<think>` tags. Added rule 10 to `SYSTEM_PROMPT` instructing the assistant to extract document content directly without discussing prompt structures.
- **Markdown Security & Formatting**: Hardened `renderMarkdown` in `desktop/src/pages/Chat.tsx` by escaping all HTML before applying markdown formatting, sanitizing external links (`rel="noopener noreferrer"`), and adding one-click copy buttons to code blocks.
- **Mobile Companion Viewport & Dropdowns**: Replaced negative-margin desktop layout with responsive `.chat-view-container` and bounded popover dropdowns (`maxWidth: calc(100vw - 32px)`) to prevent chat input and menus from clipping below the fold on mobile Safari and Chrome.
