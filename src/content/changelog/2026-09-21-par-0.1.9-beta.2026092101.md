# Pär v0.1.9-beta.2026092101

## What’s new in Pär v0.1.9-beta.2026092101

### Added

- **Live Web Search Integration**: Zero-configuration `WebSearchProvider` enabling
  live web search grounding during chat with provider credential and status display.
- **Local Document Folder Integration**: `LocalFolderProvider` with native directory
  picker and subfolder recursion toggle, syncing document hierarchies directly into
  Pär's encrypted knowledge base.
- **Credential Preservation on Edit**: Editing existing integrations now retains
  stored API keys and tokens when password fields are left blank, pre-populating
  known non-sensitive configurations.
- **Professional Integrations UI**: Sleek `.btn-connect-sm` compact action buttons,
  search filtering by name/description, category filter pill tabs, setup guides with
  pro tips, and responsive modal layout.

### Fixed

- **Home Hub LAN Connectivity & State Persistence**: Bound backend to `0.0.0.0:7433`,
  unconditionally permitted RFC 1918 private subnets in CORS, and persisted Hub Mode
  enabled state to disk across restarts.
- **Tauri Async Command Runtime Panic**: Replaced blocking reqwest client with
  non-blocking TCP probing in Tauri IPC command handlers, eliminating Tokio worker
  thread panics during dev mode and sidecar health checks.
