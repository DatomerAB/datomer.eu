# Pär v0.1.9-beta.2026092401

## What’s new in Pär v0.1.9-beta.2026092401

### Added

- **Context & Rules Importer**: Ingest existing `SKILL.md`, `CLAUDE.md`, `.cursorrules`, and `copilot-instructions.md` context files seamlessly. Available through full-container drag-and-drop in Chat, dedicated import actions in Profile (Personas & General), and Onboarding Screen 1.
- **In-Chat Context Import Modal**: Dropping or attaching rule files offers 3 actionable choices: inject into current prompt turn, persist as a custom Persona / system directive for all future conversations, or attach for file analysis.
- **Goal-Connected Onboarding Chips**: Quick selection chips for core goals and communication preferences (`⚡ Concise & direct` preselected) with connected integration recommendations (Coding → GitHub, Productivity → Calendar/Todoist, Sweden → 1177/Hemnet/PostNord).
- **Live In-Chat Download Banner**: Real-time progress bar displaying model name and percentage completion during model download with auto-initialization upon completion.
- **Personalized Chat Starters**: Tailored starter prompt pills for instant 1-click insertion into the composer across coding, debugging, pitching, and planning workflows.
- **Dynamic Hardware Model Recommender**: `GET /api/models/gguf/recommended` evaluates live RAM via `_available_ram_gb()` and selects optimal models from `routing.yaml` matching available system headroom.

### Changed

- **WCAG 2.1 AA Accessibility Overhaul**: Upgraded color palette (`--text-muted` to `#A3A3A3`, `--text-faint` to `#787878`) ensuring 5.5:1+ text contrast against dark backgrounds; elevated all micro-text to at least 12px (`.75rem`); added `:focus-visible` keyboard focus indicators.
- **Universal Select Element Design**: Standardized `<select>` dropdowns across macOS WKWebView, Windows Edge WebView2, and Linux WebKitGTK with sleek custom SVG chevrons and theme-aware dark tokens.
- **Closed Thought Blocks by Default**: Model deliberation blocks (`<think>`, `<thought>`, `<reasoning>`, `[THOUGHT]`) render as closed accordions (`<details class="think-accordion">`) by default, keeping answers clean and readable.
- **Default Concise Tone**: Initialized active chat tone to `"tone_concise"` on fresh installs, paired with a prompt prefix directing models to lead with concise bullet points and eliminate conversational filler.
- **Models Page Redesign**: Filtered noisy plumbing tags (`transformers`, `gguf`, `llama-cpp`), removed internal `score` and `0.00 quality` metrics from card interfaces, formatted human-readable titles, and added quick filter buttons (*Recommended for your device*, *Fastest*, *Deep / Smartest*, *Downloaded*).
- **Cross-Platform Compatibility**: Enhanced RAM and disk detection across macOS, Windows (`GlobalMemoryStatusEx`, drive anchor roots), and Linux (`/proc/meminfo`), with CRLF-to-LF line ending normalization.
- **Status Bar Tray & Window Management**: Fixed duplicate tray configuration in `tauri.conf.json`, applied macOS-only template icon masking with high-contrast rendering on Windows/Linux, and added window unminimize on tray click.
- **Feature Tour Polish**: Replaced duplicate slide #1 with Local Intelligence & Home Hub LAN pairing overview, and relocated "Skip tour" to the top right to avoid accidental clicks.
