# Pär v0.1.3-beta.2026090601

## What’s new in Pär v0.1.3-beta

### Smarter auto model selection
- Pär now picks the best local model for each prompt automatically. It weighs
  available RAM, context-window fit, model capabilities, whether a model is
  already downloaded, and how well each model has performed on similar tasks
  in the past.
- Long prompts are pre-checked against the chosen model’s context window so
  you get fewer “context length exceeded” errors.
- If the first-choice model is unavailable, Pär falls back through a safe
  chain of alternatives instead of stopping with an error.

### Explainable routing
- The active model label in chat now tells you why a model was chosen (for
  example, “best fit for code tasks” or “already loaded in memory”).
- Thumbs-up and thumbs-down buttons let you give explicit feedback on model
  choices, which feeds back into future routing decisions.

### Faster, more reliable tool use
- Tool decisions now reuse the same model as the chat turn, so Pär no longer
  loads a second model just to decide whether to call a calendar, task, or
  search tool.

### Better testing and documentation
- Model routing is now covered by deterministic unit tests with isolated
  configurations.
- A full data-architecture document has been added to the docs folder,
  including a conceptual and physical data model of the encrypted local vault.
