# Pär v0.1.9-beta.2026091403

## What’s new in Pär v0.1.9-beta.2026091403

### Added

- **Universal Mobile Companion Ergonomics**: Full-screen standalone PWA experience with dynamic viewport height (`100dvh`), iOS safe area inset handling, responsive slide-out navigation drawer, and automatic 16px minimum font size to eliminate iOS Safari input zoom.
- **On-Screen QR Code Pairing**: Desktop Settings renders an instant pairing QR code so phones and tablets can scan and connect without typing IP addresses.
- **Brand-Aware Device Detection**: Automatically recognizes client hardware (iPhone, iPad, Samsung Galaxy, Google Pixel, Huawei, Android) during pairing.

### Fixed

- **FastAPI Lifespan Migration**: Replaced deprecated `@app.on_event("startup")` and `@app.on_event("shutdown")` with modern `@asynccontextmanager` lifespan handlers.
- **CI Self-Hosted Toolchain Resolution**: Automatically discovers and links Rust/Cargo toolchain paths on non-interactive self-hosted runners.
